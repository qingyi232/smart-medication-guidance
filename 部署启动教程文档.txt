================================================================================
    基于智能终端用药指导系统 —— 部署启动教程文档（零基础版）
================================================================================

项目由三个服务组成：
  1. Node.js 后端 API 服务（端口 3000）
  2. Python ML 预测服务（端口 5000）
  3. Android 客户端 App

下面按顺序详细说明。


================================================================================
第一章  环境准备 —— 需要安装的软件
================================================================================

在开始之前，你的电脑需要安装以下 5 个软件。请逐一安装。

────────────────────────────────────────────────────────────────────────────────
1.1  Node.js（后端运行环境）
────────────────────────────────────────────────────────────────────────────────

【作用】运行后端 API 服务器

【下载地址】https://nodejs.org/zh-cn
   - 选择 "LTS（长期支持版）"，建议 v18 或更高版本
   - 下载 Windows 安装包（.msi 文件）

【安装步骤】
   1) 双击下载好的 .msi 文件
   2) 一路点 "Next"，全部保持默认选项
   3) 勾选 "Automatically install the necessary tools" 选项（如果出现）
   4) 点击 "Install"，等待安装完成
   5) 点击 "Finish"

【验证安装】
   打开"命令提示符"（按 Win+R，输入 cmd，回车），输入：
      node --version
      npm --version
   如果分别显示版本号（如 v18.20.0 和 9.8.1），说明安装成功。


────────────────────────────────────────────────────────────────────────────────
1.2  Python（ML 机器学习服务运行环境）
────────────────────────────────────────────────────────────────────────────────

【作用】运行机器学习预测模型的 Flask 服务

【下载地址】https://www.python.org/downloads/

   - 选择 "Windows installer (64-bit)"

【安装步骤】
   1) 双击下载好的安装包
   2) ★★★ 重要：勾选底部的 "Add Python to PATH" 复选框 ★★★
      （这一步非常关键，不勾选的话后续命令会找不到 python）
   3) 点击 "Install Now"
   4) 等待安装完成，点击 "Close"

【验证安装】
   打开命令提示符，输入：
      python --version
      pip --version
   如果分别显示版本号（如 Python 3.12.0 和 pip 23.x），说明安装成功。


────────────────────────────────────────────────────────────────────────────────
1.3  MongoDB（数据库）
────────────────────────────────────────────────────────────────────────────────

【作用】存储用户信息、药品数据、服药记录、风险评估等所有数据

【下载地址】https://www.mongodb.com/try/download/community
   - 选择 "MongoDB Community Server"
   - Version：选择最新版本
   - Platform：Windows
   - Package：MSI

【安装步骤】
   1) 双击下载好的 .msi 文件
   2) 点击 "Next"
   3) 选择 "Complete"（完整安装）
   4) ★ 勾选 "Install MongoDB as a Service" ★
      - 选择 "Run service as Network Service user"
      - 这样 MongoDB 会作为 Windows 服务自动启动
   5) ★ 勾选 "Install MongoDB Compass" ★（可选，这是一个图形化数据库管理工具）
   6) 点击 "Install"，等待安装完成
   7) 点击 "Finish"

【验证安装】
   方法一：打开 Windows 服务管理器（按 Win+R，输入 services.msc，回车），
          找到 "MongoDB Server" 服务，状态应该是 "正在运行"。

   方法二：打开命令提示符，输入：
      mongosh
   如果进入了 MongoDB Shell（显示 test>），说明安装成功。输入 exit 退出。

【注意】如果 MongoDB 服务没有自动启动：
   1) 打开服务管理器（Win+R → services.msc）
   2) 找到 "MongoDB Server"
   3) 右键 → "启动"
   4) 建议右键 → "属性" → 启动类型设为 "自动"

第三章  启动后端 API 服务（Node.js）
================================================================================

────────────────────────────────────────────────────────────────────────────────
3.1  安装后端依赖
────────────────────────────────────────────────────────────────────────────────

1) 打开命令提示符（Win+R → cmd → 回车）
2) 进入项目的 backend 目录：
      cd /d D:\medication-guide\backend
   （请将路径替换为你实际的项目路径）
3) 执行依赖安装命令：
      npm install
4) 等待安装完成（首次安装可能需要 1-3 分钟）
5) 安装完成后，backend 文件夹下会出现 node_modules 目录

【可能遇到的问题】
   问题：npm install 报错 "ECONNREFUSED" 或下载很慢
   解决：设置淘宝镜像源后重试
      npm config set registry https://registry.npmmirror.com
      npm install


────────────────────────────────────────────────────────────────────────────────
3.2  检查环境变量配置
────────────────────────────────────────────────────────────────────────────────

用记事本打开 backend/.env 文件，内容如下：

   PORT=3000
   MONGODB_URI=mongodb://localhost:27017/medication_guide
   JWT_SECRET=medication_guide_jwt_secret_key_2026
   JWT_EXPIRES_IN=7d
   FCM_PROJECT_ID=your-firebase-project-id
   ML_SERVICE_URL=http://localhost:5000

各项说明：
   PORT             → 后端服务监听端口，默认 3000，一般不需要修改
   MONGODB_URI      → MongoDB 连接地址，如果 MongoDB 装在本机保持默认即可
   JWT_SECRET       → JWT 加密密钥，可以改成任意复杂字符串
   JWT_EXPIRES_IN   → JWT 过期时间，7d 表示 7 天
   FCM_PROJECT_ID   → Firebase 项目 ID（不配置不影响核心功能，只是推送不可用）
   ML_SERVICE_URL   → ML 预测服务地址，保持默认即可


────────────────────────────────────────────────────────────────────────────────
3.3  启动后端服务
────────────────────────────────────────────────────────────────────────────────

确保 MongoDB 服务正在运行（见 1.3 节），然后在 backend 目录下执行：

   开发模式（推荐，支持代码热重载）：
      npm run dev

   生产模式：
      npm start

【启动成功的标志】
   控制台会依次输出：
      MongoDB 已连接: localhost
      Firebase 服务账号文件不存在，FCM 推送功能将不可用     ← 正常，不影响核心功能
      服药提醒 CronJob 已启动（每分钟执行）
      漏服检测 CronJob 已启动（每小时执行）
      每日风险评估 CronJob 已启动（每天凌晨 2 点执行）
      所有 CronJob 调度任务已启动
      服务器启动成功，端口: 3000
      健康检查: http://localhost:3000/api/health

【验证是否成功】
   打开浏览器，访问：http://localhost:3000/api/health
   如果看到类似以下 JSON 内容，说明后端启动成功：
      {"success":true,"message":"智能终端用药指导系统服务运行正常","timestamp":"..."}

【可能遇到的问题】
   问题1：MongoDB 连接失败
   解决：确认 MongoDB 服务已启动（见 1.3 节验证步骤）

   问题2：端口 3000 被占用
   解决：修改 .env 文件中的 PORT 为其他端口，如 3001

【注意】★ 启动后不要关闭这个命令提示符窗口！关闭窗口服务就停止了。★


================================================================================
第四章  启动 ML 机器学习预测服务（Python）
================================================================================

────────────────────────────────────────────────────────────────────────────────
4.1  确认数据集文件
────────────────────────────────────────────────────────────────────────────────

检查 backend/ml/data/ 目录下是否存在 medication_adherence.csv 文件。
如果不存在，将项目根目录下的 medication_adherence.csv 复制到 backend/ml/data/ 下。

Windows 命令：
   copy "D:\medication-guide\medication_adherence.csv" "D:\medication-guide\backend\ml\data\"


────────────────────────────────────────────────────────────────────────────────
4.2  安装 Python 依赖
────────────────────────────────────────────────────────────────────────────────

★ 另开一个新的命令提示符窗口（不要关闭后端的窗口）★

1) 进入 ML 目录：
      cd /d D:\medication-guide\backend\ml

2) 安装依赖：
      pip install -r requirements.txt

   这会安装以下库：
      flask         → Web 框架，提供预测 API
      flask-cors    → 跨域支持
      pandas        → 数据处理
      numpy         → 数值计算
      scikit-learn  → 机器学习库
      joblib        → 模型序列化
      gunicorn      → 生产级 WSGI 服务器

【可能遇到的问题】
   问题：pip 安装很慢或超时
   解决：使用清华镜像源
      pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple


────────────────────────────────────────────────────────────────────────────────
4.3  训练机器学习模型
────────────────────────────────────────────────────────────────────────────────

在 backend/ml 目录下执行：
      python train_model.py

【训练过程输出】
   程序会执行以下步骤并输出日志：
   1) 加载原始数据集 medication_adherence.csv
   2) 执行数据预处理（特征工程）：
      - 性别编码（M→1, F→0）
      - 慢性病/药品类型/位置 One-Hot 编码
      - 血压拆分为收缩压和舒张压
      - 时间特征提取（小时、星期几、是否周末、是否夜间）
      - 按患者聚合历史特征（历史依从率、平均响应时间等）
   3) 训练 RandomForest（随机森林）模型
   4) 训练 GradientBoosting（梯度提升）模型
   5) 对比两个模型的 5 折交叉验证 AUC，选择更优的作为最终模型
   6) 输出 Top 15 特征重要性排名
   7) 保存模型文件

【训练成功的标志】
   控制台输出 "模型已保存至 .../backend/ml/models/"
   并且 backend/ml/models/ 目录下生成了 3 个文件：
      adherence_model.pkl     → 训练好的预测模型
      scaler.pkl              → 特征标准化器
      feature_columns.pkl     → 特征列名列表

【注意】训练只需要执行一次。模型保存后，后续启动 ML 服务会自动加载。


────────────────────────────────────────────────────────────────────────────────
4.4  启动 ML 预测服务
────────────────────────────────────────────────────────────────────────────────

在 backend/ml 目录下执行：
      python app.py

【启动成功的标志】
   控制台输出：
      模型加载成功，特征数: 34
      * Serving Flask app 'app'
      * Debug mode: on
      * Running on all addresses (0.0.0.0)
      * Running on http://127.0.0.1:5000

【验证是否成功】
   打开浏览器，访问：http://localhost:5000/health
   如果看到类似以下 JSON 内容，说明 ML 服务启动成功：
      {"features_count":34,"model_loaded":true,"service":"用药依从性预测服务","status":"ok"}

【注意】★ 启动后不要关闭这个命令提示符窗口！★

第五章  运行 Android 客户端

────────────────────────────────────────────────────────────────────────────────
5.1  用 Android Studio 打开项目
────────────────────────────────────────────────────────────────────────────────

1) 打开 Android Studio
2) 选择 "File" → "Open"（如果是欢迎界面则点击 "Open"）
3) 在弹出的文件选择器中，找到并选中项目中的 android 文件夹，例如：
      D:\medication-guide\android
4) 点击 "OK"
5) 等待 Gradle 同步完成（底部状态栏会显示进度，首次可能需要 5-10 分钟）

【Gradle 同步成功的标志】
   底部 "Build" 面板显示 "BUILD SUCCESSFUL"


────────────────────────────────────────────────────────────────────────────────
5.2  关于后端连接地址
────────────────────────────────────────────────────────────────────────────────

Android 客户端需要连接到 Node.js 后端服务。地址配置在：
   android/app/build.gradle 文件中的 buildConfigField：
      buildConfigField "String", "BASE_URL", "\"http://10.0.2.2:3000/api/\""

【说明】
   - 10.0.2.2 是 Android 模拟器中访问电脑 localhost 的特殊 IP
   - 如果使用模拟器运行，无需修改，保持默认即可
   - 如果使用真机调试，需要将 10.0.2.2 改为电脑的局域网 IP 地址
     查看电脑 IP：打开命令提示符，输入 ipconfig，找到 "IPv4 地址"
     例如电脑 IP 是 192.168.1.100，则改为：
        buildConfigField "String", "BASE_URL", "\"http://192.168.1.100:3000/api/\""


────────────────────────────────────────────────────────────────────────────────
5.3  运行 App
────────────────────────────────────────────────────────────────────────────────

1) 确保后端服务（第三章）和 ML 服务（第四章）都已启动且正在运行
2) 在 Android Studio 顶部工具栏：
   - 选择运行设备：点击设备下拉框，选择已创建的模拟器
   - 如果模拟器没有启动，点击旁边的三角按钮先启动模拟器
3) 点击绿色的 Run 按钮 ▶（或按 Shift+F10）
4) 等待编译和安装（首次编译可能需要 2-5 分钟）
5) App 安装完成后会自动在模拟器中打开

【App 使用流程】
   1) 首先看到登录页面
   2) 点击"注册"，填写用户名（至少3个字符）和密码（至少6个字符）
   3) 注册成功后自动登录，进入主页面
   4) 在主页面可以：
      - 添加药品（设置药品名称、剂量、服药时间等）
      - 查看今日服药计划
      - 记录服药行为（已服/漏服/跳过）
      - 查看依从性统计图表
      - 执行风险评估（调用 ML 模型预测漏服风险）
      - 查看风险评估历史
      - 编辑个人健康档案


────────────────────────────────────────────────────────────────────────────────
5.4  可能遇到的编译问题及解决方案
────────────────────────────────────────────────────────────────────────────────

问题1：Failed to resolve: com.github.PhilJay:MPAndroidChart:v3.1.0
原因：MPAndroidChart 库托管在 JitPack，网络无法访问
解决：项目已内置本地 AAR 文件，确认以下配置正确：
   android/app/build.gradle 中的依赖应为：
      implementation files('libs/MPAndroidChart-v3.1.0.aar')
   而非：
      implementation 'com.github.PhilJay:MPAndroidChart:v3.1.0'

问题2：resource mipmap/ic_launcher not found
原因：缺少应用图标资源文件
解决：确认 android/app/src/main/res/ 下存在以下目录及文件：
   mipmap-mdpi/ic_launcher.png
   mipmap-hdpi/ic_launcher.png
   mipmap-xhdpi/ic_launcher.png
   mipmap-xxhdpi/ic_launcher.png
   mipmap-xxxhdpi/ic_launcher.png
   以及对应的 ic_launcher_round.png
   和 mipmap-anydpi-v26/ic_launcher.xml、ic_launcher_round.xml

问题3：Proxy Authentication 弹窗
原因：系统代理/VPN 干扰 Android Studio
解决：File → Settings → Appearance & Behavior → System Settings → HTTP Proxy
      选择 "No proxy" 或正确配置代理

问题4：Gradle 同步失败/下载依赖很慢
解决：在 android/gradle.properties 文件末尾添加阿里云镜像：
   （注意：需要在 build.gradle 的 repositories 中添加）
   在 android/build.gradle 的 buildscript.repositories 和 allprojects.repositories 中
   添加阿里云镜像：
      maven { url 'https://maven.aliyun.com/repository/google' }
      maven { url 'https://maven.aliyun.com/repository/central' }

第七章  关于 Firebase 推送功能（可选配置）
================================================================================

Firebase Cloud Messaging（FCM）用于向用户手机推送服药提醒通知。
如果不需要推送功能，可以跳过本章。系统已做优雅降级，不配置 Firebase 也能正常运行。

如果需要配置：

【步骤1】访问 https://console.firebase.google.com/ 创建项目

【步骤2】在项目中添加 Android 应用：
   - 包名填写：com.medication.guide
   - 下载生成的 google-services.json 文件
   - 将其放到 android/app/ 目录下

【步骤3】生成后端服务账号：
   - 在 Firebase 控制台 → 项目设置 → 服务账号
   - 点击 "生成新的私钥"
   - 下载 JSON 文件，重命名为 firebase-service-account.json
   - 将其放到 backend/ 目录下

【步骤4】修改 backend/.env：
   FCM_PROJECT_ID=你的实际项目ID


================================================================================
第八章  常见问题汇总（FAQ）
================================================================================

Q1: 后端报错 "ECONNREFUSED 127.0.0.1:27017"
A1: MongoDB 服务未启动。打开服务管理器启动 MongoDB Server 服务。

Q2: ML 服务报错 "模型文件不存在"
A2: 还没有训练模型。先执行 python train_model.py 训练后再启动。

Q3: Android App 连接不上后端，请求超时
A3: 检查以下几点：
   ① 后端服务是否在运行（浏览器访问 http://localhost:3000/api/health）
   ② 如果使用模拟器，BASE_URL 应为 http://10.0.2.2:3000/api/
   ③ 如果使用真机，BASE_URL 应为 http://电脑IP:3000/api/
   ④ 检查防火墙是否阻止了 3000 端口

Q4: 模型训练效果不好（AUC 偏低）
A4: 这是正常的。该数据集目标变量 future_non_adherence 的分布不均衡（约 75%
    依从 vs 25% 不依从），且特征与目标变量的相关性较弱。系统已设计了规则引擎
    作为降级方案，ML 服务不可用时会自动使用规则评估。

Q5: 注册时提示"用户名已存在"
A5: 换一个用户名注册即可。如需清空数据库重新开始：
   打开 MongoDB Compass 或 mongosh，执行：
      use medication_guide
      db.dropDatabase()

Q6: 如何停止服务？
A6: 在运行服务的命令提示符窗口按 Ctrl+C 即可停止。

Q7: 项目路径包含中文导致报错
A7: 建议将项目移动到纯英文路径下，如 D:\projects\medication-guide\
