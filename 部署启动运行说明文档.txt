================================================================================
一、项目整体架构
================================================================================

本系统由三个部分组成，需要同时运行：

  ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
  │  Android App │────>│  Node.js    │────>│  Python ML  │
  │  (前端)      │     │  后端(3000) │     │  服务(5000) │
  └─────────────┘     └──────┬──────┘     └─────────────┘
                             │
                      ┌──────┴──────┐
                      │  MongoDB    │
                      │  数据库     │
                      └─────────────┘

  - Android App：用户操作界面（手机端）
  - Node.js 后端：业务逻辑、API 接口（端口 3000）
  - Python ML 服务：AI 风险预测模型（端口 5000）
  - MongoDB：数据存储（端口 27017）


================================================================================
二、环境要求
================================================================================

请确保您的电脑满足以下条件：

  操作系统：Windows 10/11（64位）
  内存：建议 8GB 以上（Android Studio 比较吃内存）
  磁盘空间：至少 20GB 可用空间

需要安装的软件（按顺序安装）：

  1. Node.js        （v18 或更高版本）
  2. MongoDB         （v6 或更高版本）
  3. Python          （v3.10 或更高版本）
  4. Android Studio  （最新版本）
  5. JDK             （v17，Android Studio 通常自带）
  6. Git             （可选，用于克隆代码）


================================================================================
三、软件安装步骤（详细）
================================================================================

────────────────────────────────────────────────────────────────────────────────
3.1  安装 Node.js
────────────────────────────────────────────────────────────────────────────────

  1) 打开浏览器，访问 https://nodejs.org/
  2) 下载 LTS（长期支持）版本，例如 v20.x.x
  3) 双击下载的安装包，一路点"Next"默认安装即可
  4) 安装完成后，打开"命令提示符"（按 Win+R，输入 cmd，回车）
  5) 输入以下命令验证安装：

     node --version
     npm --version

  6) 如果显示版本号（如 v20.11.0 和 10.2.4），说明安装成功

────────────────────────────────────────────────────────────────────────────────
3.2  安装 MongoDB
────────────────────────────────────────────────────────────────────────────────

  1) 访问 https://www.mongodb.com/try/download/community
  2) 选择 Windows 版本，下载 MSI 安装包
  3) 双击安装，选择"Complete"完整安装
  4) 安装过程中勾选"Install MongoDB as a Service"（作为服务安装）
     这样 MongoDB 会开机自动启动，无需手动启动
  5) 安装完成后验证：

     打开命令提示符，输入：
     mongosh

     如果进入了 MongoDB Shell（显示 test> 提示符），说明安装成功
     输入 exit 退出

  【注意】如果 mongosh 命令找不到，需要将 MongoDB 的 bin 目录添加到系统
  环境变量 PATH 中。默认路径通常是：
  C:\Program Files\MongoDB\Server\7.0\bin

────────────────────────────────────────────────────────────────────────────────
3.3  安装 Python
────────────────────────────────────────────────────────────────────────────────

  1) 访问 https://www.python.org/downloads/
  2) 下载 Python 3.10 或更高版本
  3) 双击安装，【重要】勾选底部的"Add Python to PATH"复选框！
  4) 点击"Install Now"安装
  5) 验证安装：

     python --version
     pip --version

  6) 显示版本号即安装成功

────────────────────────────────────────────────────────────────────────────────
3.4  安装 Android Studio
────────────────────────────────────────────────────────────────────────────────

  1) 访问 https://developer.android.com/studio
  2) 下载最新版 Android Studio
  3) 双击安装，按默认设置一路 Next
  4) 首次启动时，Android Studio 会自动下载 SDK 等组件，耐心等待
  5) 在 SDK Manager 中确保安装了：
     - Android SDK Platform 34（或更高）
     - Android SDK Build-Tools
     - Android Emulator（模拟器）
     - Intel HAXM（如果是 Intel CPU）或 Hyper-V（Windows 11）

五、部署运行步骤（按顺序执行）
================================================================================

────────────────────────────────────────────────────────────────────────────────
步骤 1：确保 MongoDB 正在运行
────────────────────────────────────────────────────────────────────────────────

  如果安装时选择了"作为服务安装"，MongoDB 应该已经在后台运行。
  验证方法：打开命令提示符，输入：

    mongosh

  如果能进入 MongoDB Shell，说明数据库正在运行。输入 exit 退出。

  如果 MongoDB 没有运行，手动启动：

    net start MongoDB

  或者找到 MongoDB 安装目录，运行：

    mongod --dbpath C:\data\db

  （需要先创建 C:\data\db 目录）

────────────────────────────────────────────────────────────────────────────────
步骤 2：启动 Node.js 后端
────────────────────────────────────────────────────────────────────────────────

  1) 打开命令提示符（或 PowerShell）
  2) 进入后端目录：

     cd 项目路径\backend

     例如：cd F:\medication_system\backend

  3) 首次运行需要安装依赖（只需执行一次）：

     npm install

     等待安装完成（可能需要几分钟）

  4) 启动后端服务：

     node src/app.js

  5) 看到以下输出说明启动成功：

     MongoDB 已连接: localhost
     服药提醒 CronJob 已启动（每分钟执行）
     漏服检测 CronJob 已启动（每小时执行）
     每日风险评估 CronJob 已启动（每天凌晨 2 点执行）
     所有 CronJob 调度任务已启动
     服务器启动成功，端口: 3000

  6) 验证：打开浏览器访问 http://localhost:3000/api/health
     应该看到 JSON 响应：{"success":true,"message":"..."}

  【注意】这个命令提示符窗口不要关闭！关闭就停止了后端服务。

────────────────────────────────────────────────────────────────────────────────
步骤 3：启动 Python ML 服务
────────────────────────────────────────────────────────────────────────────────

  1) 新开一个命令提示符窗口（不要关闭后端的窗口）
  2) 进入 ML 服务目录：

     cd 项目路径\ml_service

  3) 首次运行需要安装 Python 依赖（只需执行一次）：

     pip install -r requirements.txt
     （或：pip install flask scikit-learn pandas numpy joblib flask-cors）

  4) 如果 models 目录下没有 risk_model.pkl 文件，需要先训练模型：

     - 将 Kaggle 下载的 medication_adherence.csv 放在「项目根目录」（与 backend、ml_service 同级），
       或设置环境变量 ML_DATA_CSV=该 CSV 的绝对路径。
     - 在 ml_service 目录执行：python train_model.py

     训练完成后会在 models/ 目录下生成 risk_model.pkl、scaler.pkl、feature_cols.pkl、
     training_meta.pkl（共四个文件；training_meta 记录数据来源与样本量）。

  5) 启动 ML 服务：

     python app.py

  6) 看到以下输出说明启动成功：

     ==================================================
       ML Risk Prediction Service
       Model: RandomForest (23 features)
       Port: 5000
     ==================================================

  7) 验证：浏览器访问 http://localhost:5000/health
     应该看到：{"status":"ok","model":"RandomForest",...}

  【注意】这个窗口也不要关闭！

────────────────────────────────────────────────────────────────────────────────
步骤 4：在 Android Studio 中打开并运行前端
────────────────────────────────────────────────────────────────────────────────

  ★★★ 极其重要 ★★★

  Android Studio 项目路径不能包含中文或特殊字符！
  如果您的项目路径包含中文（如"毕设"、"基于智能终端..."），
  必须先将 android 目录单独复制到一个纯英文/数字路径下！

  操作方法：
  1) 在磁盘根目录创建一个英文目录，例如：

     F:\MedicationGuide\

  2) 将项目中的 android 整个目录复制到该路径下：

     F:\MedicationGuide\android\

  3) 打开 Android Studio
  4) 选择 "Open" → 选择 F:\MedicationGuide\android 目录
  5) 等待 Gradle Sync 完成（首次可能需要 5-15 分钟下载依赖）

  ────────────────────────────────────────────────────
  配置后端地址（重要！）
  ────────────────────────────────────────────────────

  打开文件：
  android/app/src/main/java/com/medication/guide/network/RetrofitClient.java

  找到 BASE_URL 配置：

  - 如果使用 Android 模拟器：
    BASE_URL = "http://10.0.2.2:3000/api/"
    （10.0.2.2 是模拟器访问宿主机的特殊 IP）

  - 如果使用真机调试（手机和电脑在同一 WiFi 下）：
    BASE_URL = "http://你电脑的IP地址:3000/api/"
    （查看电脑 IP：在命令提示符输入 ipconfig，找到 IPv4 地址）

  ────────────────────────────────────────────────────
  创建模拟器并运行
  ────────────────────────────────────────────────────

  1) 在 Android Studio 中，点击顶部工具栏的 "Device Manager"
  2) 点击 "Create Device"
  3) 选择 "Phone" → "Medium Phone"（或 Pixel 系列）→ Next
  4) 选择系统镜像 API 34 或 35 → 下载 → Next → Finish
  5) 启动模拟器
  6) 点击绿色三角形 "Run" 按钮（或按 Shift+F10）
  7) 等待编译和安装完成

  ────────────────────────────────────────────────────
  首次使用
  ────────────────────────────────────────────────────

  App 启动后会显示登录页面。首次使用需要注册账号：
  1) 点击"还没账号？立即注册"
  2) 填写用户名（至少3个字符）、密码（至少6个字符）
  3) 可选填写年龄、性别、手机号等信息
  4) 点击"注册"
  5) 注册成功后自动登录进入主页

六、后端环境变量说明（backend/.env）
================================================================================

  PORT=3000                                          ← 后端端口
  MONGODB_URI=mongodb://localhost:27017/medication_guide  ← 数据库地址
  JWT_SECRET=medication_guide_jwt_secret_key_2026    ← JWT 密钥
  JWT_EXPIRES_IN=7d                                  ← Token 有效期
  FCM_PROJECT_ID=your-firebase-project-id            ← Firebase 项目ID
  ML_SERVICE_URL=http://localhost:5000               ← ML 服务地址

  一般情况下无需修改。如果 MongoDB 安装在其他机器上，修改 MONGODB_URI。

七、常见问题排查
================================================================================

  问题1：npm install 报错
  ────────────────────────
  解决：尝试清除缓存后重试
    npm cache clean --force
    npm install

  问题2：MongoDB 连接失败
  ────────────────────────
  解决：确认 MongoDB 服务正在运行
    Windows 服务中查看 "MongoDB Server" 是否启动
    或手动运行 mongod

  问题3：Android Studio Gradle Sync 失败
  ────────────────────────────────────────
  解决：
    a) 确保项目路径是纯英文/数字，不含中文
    b) 检查网络连接（Gradle 需要下载依赖）
    c) 如果使用代理，在 gradle.properties 中配置代理
    d) File → Invalidate Caches → Restart

  问题4：App 无法连接后端
  ────────────────────────
  解决：
    a) 确认后端正在运行（浏览器访问 http://localhost:3000/api/health）
    b) 确认 RetrofitClient.java 中的 BASE_URL 配置正确
    c) 模拟器用 10.0.2.2，真机用电脑实际 IP
    d) 检查 AndroidManifest.xml 中是否有 android:usesCleartextTraffic="true"
    e) 检查防火墙是否放行了 3000 端口

  问题5：AI 风险评估显示"ML服务离线"
  ────────────────────────────────────
  解决：确认 Python ML 服务正在运行
    浏览器访问 http://localhost:5000/health
    如果没有运行，重新执行 python app.py

  问题6：pip install 报错
  ────────────────────────
  解决：尝试使用国内镜像
    pip install flask scikit-learn pandas numpy joblib flask-cors -i https://pypi.tuna.tsinghua.edu.cn/simple

  问题7：模拟器运行很慢
  ────────────────────────
  解决：
    a) 在 BIOS 中开启 VT-x（Intel）或 SVM（AMD）虚拟化
    b) 使用 x86_64 系统镜像而非 ARM
    c) 分配更多内存给模拟器

九、停止服务
================================================================================

  - 后端和 ML 服务：在对应的命令提示符窗口按 Ctrl+C
  - MongoDB：如果是服务模式，无需手动停止（开机自动运行）
  - 模拟器：直接关闭模拟器窗口
